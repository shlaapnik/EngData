# ДЗ 5 по инженерии данных. Марковский Артём, 466636, J3310

- `kubernetes.ipynb` ноутбук со всеми этапами по порядку, команды запускаются из него, их вывод виден текстом
- `pairs_job.py` расчёт пар навыков из ДЗ 3 по частям файла: map и reduce берутся из `../MapReduce/mapreduce_job.py`, программа печатает пик памяти своего контейнера из cgroup
- `Dockerfile`, `Dockerfile.dockerignore` образ `pairs-job:hw5`, собирается из корня репозитория, в контекст попадают только три файла
- `k8s/` манифесты: пространство имён, RustFS в кластере на папках-дисках из ДЗ 3, классы приоритета, квота
- `k8s/jobs/` манифесты заданий, которые применял ноутбук, предел памяти в них подобран по измеренному пику
- `logs/` журналы подов (`*.log`) и события Kubernetes (`*.events.log`) всех запусков
- `kubernetes.html` ноутбук в html, его собирает последняя ячейка ноутбука
- `kubernetes.pdf` отчёт (`kubernetes.ipynb` -> html -> pdf)

Кластер: Kubernetes из Docker Desktop в режиме kubeadm. Данные: RustFS из ДЗ 3 (бакет `hh-lake`, папки-диски `../rustfs/disk1..12`)

```bash
uv sync
```

потом открыть `kubernetes.ipynb` в VS Code или Jupyter с ядром из `.venv`
